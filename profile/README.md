# Agentstack

Open-source **agent skills, memory and orchestration** for coding agents.

**Make your agents behave, not just respond.**

## Products

| Repo | What |
|---|---|
| [opencode-adhd-style](https://github.com/agentic-society/opencode-adhd-style) | ADHD-friendly output styling for opencode: action-first, numbered steps, no preamble. Always-on (instructions) or on-demand (skill). |
| [universal-agent-brain](https://github.com/agentic-society/universal-agent-brain) | Local brain and skill orchestration system for coding agents. |

## Install a skill

```bash
npx skills add agentic-society/opencode-adhd-style
```
